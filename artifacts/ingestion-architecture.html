Evidence in. Rationale out.

A technology-neutral ingestion architecture that turns engineering activity into a versioned, traceable temporal evidence graph. Source platforms stay at the edge; the record contract and relationship semantics remain stable.

Canonical contract: what crosses the boundary

EngineeringRecord { identity: { canonical_id, source_id, source_kind, record_kind, repository_or_workspace } actor: { canonical_id?, source_id?, display_name? } time: { created_at?, updated_at?, observed_at, valid_from?, valid_to? } content: { title?, text?, format?, language? } change: { kind?, before?, after?, paths[], stats? } context: { project?, repo?, branch?, labels[], access? } references: [{ target_source, target_id, relation }] discussion: [{ thread_id?, parent_id?, text?, locator? }] provenance: { source_uri, locator, checksum, adapter_version, extraction_version } claims: [{ claim_kind, value, status, confidence, method, evidence_refs[] }] schema_version }

Stable core, extensible envelope

Adapters preserve original IDs and payload references, then map source-specific fields into shared concepts. Unknown source fields can be retained as namespaced extensions without contaminating core semantics.

Backward compatible schema evolution

Relationships carry their proof

Use a shared vocabulary such as AUTHORED, CHANGED, REFERENCES, DISCUSSES, SUPPORTS, JUSTIFIES, PRECEDES and RELATED_TO. Each edge records whether it is explicit, structural or inferred, plus method, confidence and evidence.

Never flatten evidence into an unexplained edge

Two clocks, when needed

Event/valid time describes when a fact applied in the software history. Observed time records when this system learned it. Keeping both supports corrections, backfills and “what did we know then?” questions.

Temporal, replayable, auditable

Ingestion lifecycle

1 · Discover & fetchScope, cursor, pagination, backfill, webhook or poll.
2 · Preserve rawChecksum, source URI, observation time, access labels.
3 · NormalizeValidate canonical envelope; dedupe; quarantine invalid rows.
4 · ExtractDeterministic structure first; semantic claims are marked.
5 · Resolve linksExplicit references, structural relations, then ranked candidates.
6 · Persist & indexTemporal graph is authoritative for relations; search is rebuildable.
7 · Retrieve evidenceTraverse time and relationships; return locators and gaps.
8 · Explain carefullyAnswer with citations, confidence, alternatives, or unknown.
